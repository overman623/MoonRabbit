# MoonRabbit

2D 궤도 회피 게임입니다. 토끼가 달 주위를 돌고, 화면을 눌러 방향을 바꿉니다. 운석을 피하고 코인을 모읍니다.

이 게임의 코드는 AI를 사용하지 않고 직접 작성했습니다. 생성형 AI로 코드를 만들거나 고치지 않았습니다.

플레이: https://overman623.github.io/MoonRabbit/

이 저장소는 WebGL 빌드입니다. 원본 Unity 프로젝트 경로는 `MoonRabbit/`이고, 빌드 산출물은 `MoonRabbit/MoonRabbit_Build`입니다.

## 플레이

- **시작:** Intro 씬 다음 Game 씬. 시작 팝업의 시작 버튼으로 플레이가 시작됩니다.
- **이동:** 플레이어는 달 중심, 반지름 1.6 궤도를 돕니다. 시작 각속도는 2입니다.
- **조작:** 화면 클릭으로 시계 방향과 반시계 방향을 바꿉니다. 방향이 바뀔 때 짧은 알림 이펙트가 나옵니다.
- **체력:** 하트 3개. 운석에 맞으면 1개 감소하고, 0이 되면 게임 오버입니다. 무적 중에는 피해를 받지 않습니다.
- **점수:** 플레이 중 1초마다 +1. 코인을 먹으면 +50. 일시정지 중에는 시간이 멈추고 점수도 오르지 않습니다.
- **운석:** 달을 향해 날아옵니다. 유지 개수는 15개입니다. 무적 상태에서 맞으면 튕기며 사라집니다.
- **코인:** 유지 개수는 1개입니다. 플레이어가 먹으면 점수와 효과음이 들어가고, 달에 닿으면 사라집니다.
- **당근:** 하트가 3개 미만이 되면 30초마다 궤도에 나타납니다. 플레이어보다 느리고(각속도 3 × 0.3), 먹으면 3초 무적이 됩니다. 무적 중에는 다시 나오지 않습니다.
- **일시정지 / 설정:** 게임 화면의 일시정지, 설정 버튼. 일시정지는 플레이어, 당근, 운석, 코인과 스폰을 멈춥니다.
- **게임 오버:** 유령 이펙트 후 `Time.timeScale = 0`, 게임 오버 팝업에서 점수와 재시작·종료를 보여 줍니다.
